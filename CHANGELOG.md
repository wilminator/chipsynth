# CHANGELOG

Releases are made by python-semantic-release from Conventional Commit messages (see `RELEASING.md`); it adds each new
version below the marker. Only what is above the marker is hand-written.

## 0.1.0 (first public release)

The first version published to PyPI, as it stood when packaging was added:

* the chip synthesizer (pulse, saw, triangle, sine, noise voices and two DAC sample channels), the MML tune language,
  the player and the seeded tune generator;
* NES-style DPCM samples with WAV import options;
* Standard MIDI, FamiStudio text (import and export) and GoatTracker 2 import;
* the `.csp` song package, and the `chipsynth` command line (list, dump, build, import, export, export-song, generate);
* the pygame song composer (`chipsynth-composer`), with its File menu for importing and exporting.
